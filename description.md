# Аналитический кейс: EduPulse

## Контекст

Ты - аналитик данных в EdTech-компании **EduPulse**. Платформа предлагает онлайн-курсы по IT-специальностям (Python, SQL, Data Analytics, ML) и работает по подписочной модели: free / basic (990₽/мес) / pro (2490₽/мес)

Руководство озабочено двумя вещами:
1. Отток пользователей растёт и непонятно, какие сегменты уходят
2. Бюджет на маркетинг ограничен - нужно понять, какие каналы привлечения дают самых ценных пользователей

Тебе выгрузили данные о ~1500 пользователях. Твоя задача - провести полный аналитический цикл и подготовить отчёт с рекомендациями
